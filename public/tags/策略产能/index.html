案例：策略产能，增长团队的第二增长曲线

案例：策略产能，增长团队的第二增长曲线 适用场景：5 人以上增长团队，人均产能遇到天花板，招人也涨不动业务规模 核心洞察：大部分增长团队的策略时间占比不到 20%——80% 的时间花在了操作上 服务周期：2 周诊断 + 3 个月体系落地 本案例已完全脱敏，不指向任何特定客户或行业；服务范围不含游戏（含手游 / 休闲 / 中重度）行业。 什么是策略产能 策略产能 = 增长团队把数据、经验和判断转化为有效增长动作的能力。 它不等于加班时长，也不等于 campaign 数量——很多团队看起来很忙，但忙的都是"数据搬运"，不是"策略判断"。 团队类型 操作时间占比 策略时间占比 人均产能相对水位 低效团队 80% 20% 基线 普通团队 50% 50% 3× 基线 高效团队 20% 80% 10× 基线以上 问题诊断：你的团队卡在哪了？ 第一层：操作瓶颈 业务方每天切 5 - 8 个后台，手动粘数做报表 批量创建 campaign 要一个一个填 素材上传、打标、跟踪全靠人工 结果：招再多人，人效也上不去，人均产能长期卡在低水位 第二层：信号瓶颈 没有统一的红绿看板，哪个 campaign 该加该减全凭感觉 异常发现慢，等发现跑崩了，预算已经烧没了 素材疲劳全靠"感觉这个素材跑了挺久了" 结果：策略判断不准，试错成本高，ROI 忽高忽低 第三层：策略瓶颈 资深专家的经验存在脑子里，人走了经验就没了 新人上手要 3 个月，全靠师傅带 动作不复盘：调了预算、换了素材，有没有效不知道 没有可复用的策略模板，每次新方向都从零开始 结果：团队规模越大，管理成本越高，增长遇到天花板 我们的提升方案 第一步：减操作（把操作时间从 80% 降到 20%） 统一数据入仓 + ROI360 看板：不用再切后台粘数 跨渠道批量创编工具：模板化创建，一次填好，多平台同步 自动命名规范 + 维度管理：告别"campaign_123_final_final" 价值：每人每周多出 3 天时间做策略 第二步：推信号（把策略判断的信噪比提升 10 倍） 红绿看板：每个 campaign 自动打分，红的停，绿的加 异常预警：分钟级监控，ROI 掉了、成本涨了自动告警 素材疲劳检测：曝光频次、转化率衰减自动提示 机会清单：被低估的场景、素材、定向自动推荐 价值：策略判断从"凭感觉"变成"看信号"，决策准确率提升 第三步：沉策略（把个人经验变成团队资产） Action Tracking 机制：每个业务动作都有"动作前 → 动作后 → 预期 → 结果"的闭环 策略模板库：优秀的预算、定向、素材组合沉淀成模板，新人拿来就能用 动作审计日志：什么人、什么时候、做了什么动作、效果如何，全记录 规则引擎 + Agent 建议：把成熟的策略变成自动规则，AI 辅助决策 价值：新人上手从 3 个月缩短到 2 周，团队经验不随人走 交付清单 📊 《策略产能诊断报告 + 团队现状评分》 ⚙️ 《减操作工具清单 + 优先级落地路线图》 🚥 《红绿看板设计 + 异常告警阈值清单》 📋 《Action Tracking 机制 + 复盘 SOP》 🧩 《策略模板库框架 + 运营方案》 🗺️ 《3 个月策略产能提升路线图》 结果 我们服务过的团队，3 个月内普遍能拿到这些结果： ...
