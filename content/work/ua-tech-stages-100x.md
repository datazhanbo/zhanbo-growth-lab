> **案例性质**：行业观察型案例，基于公开资料与一条匿名产品曲线整理；不是客户交付案例，不代表任何雇主或客户观点。
>
> **观察对象**：仍在持续投放的出海休闲产品，跨越约三四年的日活 / 买量花费曲线。
>
> **核心问题**：后台数字不难看时，团队最容易追问"再加多少预算"；真正该问的是——我们卡在买量技术的哪一段，下一段红利窗口是否已经打开。

---

## 曲线证据：两次交叉，和一直平行的日活月活

![一条仍在投放的产品：两次交叉，和一直平行的日活月活](/posts/2026-11-13-ua-tech-stages-100x/ua-tech-stage-curve.png)

*日活、月活各自相对自身起点做成倍数（1x / 10x / 100x）；花费与收入用同一基准。不标注绝对量级，色带对应技术红利窗口。*

三个可公开的事实：

1. **日活与月活几乎一直平行**——产品力在线，量加进去，活跃结构没被掀翻。
2. **花费与收入两次交叉**——前一次是冷启动很快转正；后一次出现在活跃接近 100x、渠道火力全开的时候。
3. **中间有一段花费走平、活跃仍长**——红利并不都来自加预算，产品实验和留存打磨同样在推曲线。

边界必须说清：最右侧花费陡升是**自动 / 批量阶段打满**的结果，不是第五阶段已经落地。第二次交叉才是第五阶段的门槛。

---

## 五段红利窗口：不是线性升级，是会过期的窗口

| 阶段 | 主轴 | 红利来自 | 过期信号 |
|---|---|---|---|
| **1 · 预算门槛 / 调参** | 优化师拧参数、小额多组 | 先把量买进来，冷启动快速转正 | 同样动作只剩平均成本 |
| **2 · 批量 / 聚合** | 批量创编、平台聚合、跨账户操作 | 产能与学习通量上升 | 批量变成标配，产能不再稀缺 |
| **3 · 自动 / 批量打满** | 自动化规则、自动出价、花费陡升 | 渠道火力全开，规模上去 | 花费与收入再次交叉，粗放 ROAS 不够用 |
| **4 · 素材驱动** | 素材创意 + AIGC 工具杠杆 | 角度产能放大，创意仍是关键变量 | 工具普及后只剩创意差异 |
| **5 · agent 执行 / 人做决策** | 点火、放量、停投由人把关 | 更快试错 + 可审计决策 | 窗口刚开，尚未全面落地 |

素材战争的技术部分基本结束：**AIGC 工具够用，真正稀缺的是创意角度，不是工具本身**。把"上 AIGC"当成下一波技术红利，是找错了窗口。

---

## 第五阶段的门槛：三件能力要现在启动

行业窗口已经开到第五阶段的启动和萌芽，不必等"全面 agent 化"。三件事必须并行启动：

| 能力 | 要回答的问题 | 判断边界 |
|---|---|---|
| **agentic 买量** | 哪些执行可以交给 agent，哪些点火 / 放量 / 停投必须人拍板？ | 无人值守不是目标；开源样本里 agent 设计实验、工程师审批后才上线 |
| **iROAS（增量 ROAS）** | 如果不花这笔钱，收入会少多少？ | 平台 ROAS 达标不等于生意增量；放量前用 holdout / geo-holdout / 阶段性停投问一次 |
| **自有测量** | 计划、素材、效果由同一平台生成并判定时，广告主手里有没有反驳证据？ | 自有收入账、MMP、平台三本账对齐；归因窗口 / 时区 / 币种 / 切换日期留底 |

**没有可审计的测量和增量判定，agent 只会更快地放大一本你核验不了的账。**
