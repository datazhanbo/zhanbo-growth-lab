# 增长决策可信度自检清单

针对**即将拍板的一次决策**逐项勾选。不确定的，先标「待确认」。每一项后面那句是「为什么要问」。

## 1. 数据可信（口径 / 归因 / BI vs 业务后台）

- [ ] **核心指标有书面口径**：定义、分子分母、时间窗、去重规则写清楚，且相关方认可。
  *为什么：口头口径一多，周环比与跨团队对账必然打架。*
- [ ] **事件 / 字段与埋点版本可追溯**：知道当前看板用的是哪一版埋点与清洗规则。
  *为什么：静默改埋点会让「变好了」其实是口径变了。*
- [ ] **归因规则写明且稳定**：归因窗口、触点优先级、是否含自然量，审批前后一致。
  *为什么：归因一改，渠道 ROI 可以在没有业务变化时大幅波动。*
- [ ] **BI 与业务后台关键指标对过账**：近 7–14 天关键指标偏差在约定阈值内，或已知原因已记录。
  *为什么：两边对不上时，任何「涨了 / 跌了」都不可单独采信。*
- [ ] **延迟与回刷已说明**：报表是 T+1 还是实时、会不会回刷历史，决策方知情。
  *为什么：用未回刷数据拍板，事后数字回落会被误判为「策略失效」。*
- [ ] **异常与缺失有处理约定**：空值、重复、机器人、测试号是否剔除，规则可复查。
  *为什么：脏数据进分母，转化率与成本会被系统性扭曲。*
- [ ] **样本与总体边界清楚**：当前结论适用的用户 / 市场 / 端，不外推到未覆盖范围。
  *为什么：局部好看就推全量，是最常见的过度自信来源之一。*

## 2. 实验可信（样本量 / 干扰 / OEC / 护栏 / 结论采纳）

- [ ] **事先写了假设与 OEC**：主指标唯一且可行动；次要指标与护栏列全。
  *为什么：事后挑显著指标，等于没做实验。*
- [ ] **样本量 / 最小可检效应事先算过**：未达计划停表或「提前偷看」有记录与处理规则。
  *为什么：样本不够就结案，假阳性与假阴性都会升高。*
- [ ] **分流与曝光符合设计**：进组条件、曝光日志、占比与设计一致，无大面积串组。
  *为什么：串组与曝光不全会稀释或夸大真实效果。*
- [ ] **干扰因素已排查**：同期大促、预算倾斜、客户端发版、竞品动作等已记录影响判断。
  *为什么：外部冲击没隔离时，因果解释不可靠。*
- [ ] **护栏指标未踩红线**（或踩线已有明确取舍）：体验、合规、成本、留存等护栏有阈值。
  *为什么：主指标涨、护栏崩，全量往往是亏的。*
- [ ] **多重比较与细分有约束**：切片结论不单独作为全量依据；预注册切片优先。
  *为什么：切得越多，「总能找到显著」越容易。*
- [ ] **结案标准事先约定**：谁有权宣布成功 / 失败 / 需重做；灰度与全量门槛分开。
  *为什么：没有采纳规则，实验会变成辩论素材而不是决策输入。*
- [ ] **失败与持平也可归档**：负向与无显著差异同样进入知识库，避免重复踩坑。
  *为什么：只留赢的实验，组织会系统性高估打法。*

## 3. 决策链路（谁拍板 / 停止条件 / 复盘）

- [ ] **决策人与知情范围明确**：最终拍板人、建议人、否决权写清；会前材料齐全。
  *为什么：多人「都觉得可以」却无人负责，事后无法追责与学习。*
- [ ] **可选动作写全**：全量 / 灰度 / 继续实验 / 停 / 改假设，而不是只有「做不做」。
  *为什么：二元选择会迫使在证据不足时硬选一边。*
- [ ] **停止与熔断条件事先有**：预算上限、护栏红线、时效窗口到点必须复盘。
  *为什么：没有停止条件，亏损投放与坏实验容易拖成「再看两天」。*
- [ ] **决策依据可回溯**：用了哪张表、哪次实验、哪份纪要，链接或附件可查。
  *为什么：无法回溯的决策，复盘只能靠记忆与立场。*
- [ ] **复盘时间与问题单已定**：上线 / 放量后何时看什么指标、谁主持、产出是什么。
  *为什么：没有复盘点，成功不可复制，失败不可沉淀。*
- [ ] **激励与指标无直接冲突**：考核指标与本次 OEC / 长期健康不互相拆台，或冲突已明示。
  *为什么：考核驱动会诱使优化短期代理指标而伤害真实目标。*

## 4. ROI 互掐常见断点

- [ ] **「收入」定义对齐**：GMV / 实收 / 退款后 / 含税与否，投放、产品、财务用同一套或已映射。
  *为什么：收入分子不一致，是 ROI 对不上的第一大户。*
- [ ] **「成本」边界对齐**：媒体费、服务费、优惠券、人力、带宽是否同口径计入。
  *为什么：一方只算媒体费、一方摊全成本，结论必然相反。*
- [ ] **时间窗对齐**：消耗日 vs 转化日、自然月 vs 活动窗，对账时窗一致。
  *为什么：错位几天就能让「赚钱」变成「亏钱」。*
- [ ] **新老客 / 渠道互斥规则一致**：共享转化如何分、是否允许重复计算，各方同意。
  *为什么：重复记账会让每个渠道都「很值」。*
- [ ] **增量 vs 总量说清**：报的是 uplift 还是绝对量；有无对照组或稳健的增量估计。
  *为什么：把总量当增量，会高估投放与功能价值。*
- [ ] **对账差异有 owner**：BI、投放、财务谁牵头解释缺口，时限与升级路径清楚。
  *为什么：没人负责的差异会变成永久的「各说各话」。*
