# 增长决策可信度诊断

> **试点价（2026-11）**：**¥1,000／小时**。
> 适配沟通后确认覆盖主题与大致投入，问题谈清楚就可以停。完整菜单见 [服务与合作](/services/)。

回答一个问题：**当前看到的数据、做过的实验和准备投入的预算 / Agent，到底能不能信？**

不确定从哪开始？可以先做 [广告数据可信度快检](/tools/checkup/) 或 [实验能力自检](/tools/experiment-checkup/)，再约一次**免费适配沟通**，一起判断从哪一档深度开始。

诊断阶段只读：不接管投放、不改生产环境、不替研发团队做工程交付。深度随双方确认的投入伸缩。

---

## 适合谁

对增长结果负责的 **CEO / COO、业务 / 增长 / 数据负责人**，团队已经有投放、归因、BI、实验或发行相关数据，并遇到下面一类情况：

- 业务后台、归因、BI 口径不一致，ROI / ROAS 在预算会上反复争议；
- 进入新渠道 / 新市场时，难以判断历史经验能否复用；
- 实验在做，但量少、结论不被采信，或结果互相污染；
- 准备自建或采购实验平台、发行底座、BI，立项前需要一次外部判断；
- Agent 停在 Demo，不确定数据与权限底座是否撑得住；
- 融资、董事会或年度预算前，需要把「增长能不能信」讲清楚。

如果团队还在很早期、数据沉淀很少，也可以先从免费适配沟通聊起，不必直接做诊断。

---

## 覆盖范围

按你的卡点选择主题，可以组合，也不必一次做全：

| 主题 | 看什么 | 通常不包含 |
|---|---|---|
| **数据与口径** | 指标定义、归因链路、业务后台 vs 归因 vs BI 的差异 | 重建数仓、改 ETL |
| **实验可信度** | 分流 / 层、统计、护栏、实验治理与结论采用 | 代跑实验、长期实验运营 |
| **决策链路** | 从数据到判断、执行、复盘的断点与责任人 | 替业务拍板、代投 |
| **发行 / 增长底座** | 预算与渠道决策所依赖的数据是否可信 | 代投代运营 |
| **AI / Agent 前置** | 数据权限、审计、回滚、目标函数是否就绪 | 直接交付 Agent 产品 |

工作方式：只读看板 / 文档 + 关键人短访谈，不需要生产环境的写权限。

## 深度与投入

| 深度 | 大约投入 | 你会带走 | 你这边大致需要 |
|---|---|---|---|
| **澄清** | **2–4 小时** | 一页断点清单 + 是否值得继续的建议 | 一次短会 + 少量脱敏截图 |
| **标准** | **8–16 小时** | 评分卡 · 问题地图 · 优先级矩阵 | 2–3 人短访谈 + 看板只读 |
| **完整** | **20–40 小时** | 上列 + 90 天动作建议 · 管理层对齐纪要 · 完成证明 | 关键人访谈 + 一次对齐会 |

- 单价 **¥1,000／小时**；
- 多数合作从澄清或标准开始，需要时再加深；
- 适配沟通后 **24 小时内**给出书面提案：覆盖主题、投入区间与产出。

## 合作边界

不做代投，不改生产配置，不做人月外包，也不承诺销售额或「几天修好一切」。诊断需要团队内部有明确的对接人。

---

## 诊断之后

判断成立时，常见的下一步有：数据 / 投放底座 PoC、实验体系共建、发行决策底座、单场景 Agent PoC、阶段性平台共建——都按里程碑推进、可以暂停。诊断阶段也会一起分清：哪些适合继续合作，哪些更适合自建或找其他伙伴。
