# 增长决策可信度诊断

> **试点价（2026-11）**：**¥1,000／小时**；**不固定工期**。适配沟通后给小时区间与止损线，做到够用就停。菜单与抵扣规则见 [服务与合作](/services/)。

> 这是自检与适配沟通之后的正式进场产品。回答一个问题：**当前看到的数据、做过的实验和准备投入的预算 / Agent，到底能不能信？**

还不确定要不要进场？先花 5 分钟做 [广告数据可信度快检](/tools/checkup/)（营销买量）或 [实验能力自检](/tools/experiment-checkup/)（实验平台），提交结果即可预约免费适配沟通。

不接管投放、不改生产环境、不替你的研发团队做工程交付。用只读方式，把最影响业务判断的断点找出来，并给出优先级矩阵和分阶段建设建议；具体节奏按你的资源与书面小时区间共同确定。

## 适合谁

对增长结果负责的 **CEO / COO、业务负责人、增长负责人、数据负责人**，且团队已经在跑投放、归因、BI 或产品数据，开始遇到下面一类情况：

- 业务后台、归因平台、BI 看到的是三套数，ROI / ROAS 口径在预算会上反复吵架；
- 正在加码新渠道或新市场，但历史数据无法判断哪些经验可以复用；
- 已经在做 A/B 实验，但实验量少、结论没人信、结果互相污染；
- 准备自建或采购实验平台、BI、数据中台，立项前需要一次外部判断；
- 团队在尝试 AI Agent，却停留在聊天、报表和 Demo，担心数据底座撑不起自动化；
- 融资、董事会、年度预算前需要把"增长到底行不行"讲清楚。

如果团队还没有任何数据沉淀、也没有明确的业务负责人，这个诊断可能为时尚早——可以先约免费适配沟通。

## 做什么，不做什么

| 维度 | 诊断范围内 | 诊断不做 |
|---|---|---|
| 数据 | 指标口径、归因链路、BI 与业务后台差异、关键看板可信度 | 不重建数据仓库、不改 ETL |
| 实验 | 实验平台准备度、流量分层、统计可信度、实验治理 | 不替团队跑实验、不做长期实验运营 |
| 决策 | 从数据到决策到执行到复盘的链路断点 | 不替业务方做决定、不代投 |
| AI 前置 | 哪些场景适合 Agent、数据 / 权限 / 审计是否就绪 | 不直接交付 Agent 产品 |
| 工作方式 | 关键角色访谈、只读数据快照、现有文档与看板审阅 | 不要生产权限、不连生产数据库 |

**客户需要投入**：关键角色访谈、只读数据 / 看板 / 文档访问、对接人时间。常见完整诊断大约落在数十小时量级，以书面确认的小时区间为准。

## 计费与节奏

- **单价**：¥1,000／小时（试点）
- **不锁死天数**：适配沟通后给出「最小够用」与「完整六件交付」两档小时区间；可先买最小包，不够再追加
- **结算**：按实际投入小时；停止条件触发时按已完成里程碑 / 已投入小时结算
- **典型节奏（示例，非合同工期）**：对齐与访谈 → 事实确认 → 问题地图与优先级 → 管理层对齐；深度随小时投入伸缩

## 你会拿到的交付（按投入深度取舍）

1. **决策可信度评分**：数据 / 指标 / 归因 / 实验 / 决策流程 / AI 前置六个维度的成熟度评估；
2. **问题地图**：哪些断点正在直接影响预算、产品或 AI 投入，按影响 × 修复成本排序；
3. **优先级矩阵**：不依赖大项目、可以先启动的具体动作与责任人；
4. **分阶段建设建议**：哪些值得做 PoC、哪些应进入平台共建、哪些应该暂缓；
5. **一次管理层对齐会**：把争议点摆到桌上，形成"先做什么、暂时不做什么、谁负责"的共识；
6. **完成证明一页**（便于报销）。

## 诊断之后，自然升级的路径

诊断本身不预设后续一定要继续合作。如果判断成立，常见的下一步有：

- **数据治理 / 投放数据底座 PoC**：6–12 周，把关键口径和 ROI 报表跑通；
- **实验体系专项诊断与共建**：针对高并发、流量框架、统计可信度等更难的问题；
- **单场景决策工作流 / Agent PoC**：在已经可信的数据上，做一个带审批、审计、回滚的真实场景；
- **阶段性平台共建**：多团队、多市场、3–6 个月或分阶段，里程碑驱动、可暂停。

我不做代投、不做外包人月、不做"什么都接"的项目。诊断阶段就会明确告诉你，哪些事适合我、哪些应该找别人或自建。

## 合作方式

**按小时计费、书面小时区间、可停**——卖的是判断，不是堆工时。具体提案会在适配沟通之后 24 小时内给出，结合：

- 业务复杂度与对接团队数量；
- 是否包含管理层对齐会和异地差旅；
- 是否需要额外做数据脚本或看板走查；
- 是否同意以匿名方式沉淀为可公开案例。

如果你只是想要一份"便宜的人天报告"、又不准备提供只读资料与关键访谈，我们可能不是最合适的合作对象。
