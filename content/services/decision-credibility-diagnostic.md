# 增长决策可信度诊断

> **试点价（2026-11）**：**¥1,000／小时** · **工期不锁死**（不再要求「必须两周」）。  
> 适配沟通后给小时区间与止损线，做到够用就停。菜单见 [服务与合作](/services/)。

> 回答一个问题：**当前看到的数据、做过的实验和准备投入的预算 / Agent，到底能不能信？**

还不确定？先做 [广告数据可信度快检](/tools/checkup/) 或 [实验能力自检](/tools/experiment-checkup/)，再约**免费适配沟通**——先判断值不值得买小时，再谈深度。

不接管投放、不改生产、不替研发做工程交付。只读找断点；深度按你愿意投入的小时伸缩。

---

## 适合谁

对增长结果负责的 **CEO / COO、业务 / 增长 / 数据负责人**，团队已有投放、归因、BI、实验或发行相关数据，并出现例如：

- 三套数互掐，ROI / ROAS 在预算会上吵架；
- 新渠道 / 新市场经验无法复用；
- 实验量少、结论没人信、互相污染；
- 准备自建或采购实验平台、发行 / 分发底座、BI——立项前要外部判断；
- Agent 停在 Demo，担心底座撑不住；
- 融资 / 董事会 / 年度预算前要把「增长能不能信」讲清楚。

尚无数据沉淀、也无负责人——先约免费适配沟通即可，不必先买诊断。

## 覆盖范围（按主题，可裁剪）

按你的卡点选主题，**不必一次做全**：

| 主题 | 看什么 | 典型不问什么 |
|---|---|---|
| **数据与口径** | 指标定义、归因链路、业务后台 vs 归因 vs BI 差异 | 不重建数仓、不改 ETL |
| **实验可信度** | 分流 / 层、统计、护栏、实验治理与采用 | 不替你跑实验、不做长期运营 |
| **决策链路** | 从数 → 判断 → 执行 → 复盘的断点与责任人 | 不替业务拍板、不代投 |
| **发行 / 增长底座** | 预算与渠道决策依赖的数据是否可信 | 不做代投代运营 |
| **AI / Agent 前置** | 数据权限、审计、回滚、目标函数是否就绪 | 不直接交付 Agent 产品 |

工作方式一律：**只读**看板 / 文档 + 短访谈；不要生产写权限。

## 深度档：降低决策难度

| 深度 | 大约小时（示例） | 带走什么 | 客户侧投入 | 适合什么时候选 |
|---|---|---|---|---|
| **澄清** | **2–4** | 一页断点清单 + 「值不值得继续」建议 | 1 次短会 + 少量脱敏截图 | 还不确定问题真假；先把决策成本压到最低 |
| **标准** | **8–16** | 评分卡 · 问题地图 · 优先级矩阵 | 2–3 人各 1 次短访谈 + 看板只读 | 已知互掐 / 实验不信，要可执行的优先级 |
| **完整** | **20–40** | 上列 + 90 天动作建议 · 管理层对齐纪要 · 完成证明 | 关键人访谈 + 一次对齐会 | 要进立项会 / 报销 / 团队对齐 |

- 单价固定：**¥1,000／小时**
- 可先买澄清或标准，不够再追加；**默认建议从澄清或标准起步**
- 停止条件触发时按已投入小时结算
- 书面提案在适配沟通后 **24 小时内**给出（小时区间 + 止损线 + 覆盖主题）
