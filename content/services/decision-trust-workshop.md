# 增长决策可信度 · 高管工作坊

一天内让 CEO / 增长 / 数据用**同一套语言**讨论：数能不能信、实验结论能不能用、下一步先做什么。

**试点价**：见 [服务与合作](/services/)（线上团队 ≤8 人）。

## 会前（客户准备，约 2 小时）

- 贴 1–2 张你们最常吵的 ROI / 实验结论截图（脱敏）
- 填写开源 [决策可信度 checklist](https://github.com/datazhanbo/growth-decision-trust-checklist) 自评
- 确认参会人：至少业务拍板人 + 数据/分析负责人

## 建议日程（可按团队定制）

下面是一版常用 agenda。每个团队卡住的位置不同，适配沟通后会按你们的情况调整模块和时间，也可以只聚焦其中半天。

### 上午 · 信任从哪破

1. **开场对齐**（20′）：今天要带走的一页「先做三件事」
2. **OEC 与护栏**（50′）：什么叫可决策指标；北极星 / 护栏 / 代理指标怎么分
3. **ROI 口径断点拆解**（60′）：业务后台 vs 归因 vs BI 的典型断点（对照你们的截图）
4. **小结**（15′）：列出本场已确认的事实 vs 仍是假设

### 下午 · 实验与决策链路

5. **实验成熟度 L1–L4**（45′）：分流 / 统计 / 指标 / 文化；你们落在哪一级
6. **决策链路**（45′）：谁拍板、什么数据触发暂停、复盘节奏
7. **产出工作坊**（60′）：共同写一页——先做 / 暂不做 / 责任人 / 14 天验证
8. **可选下一步**（15′）：是否按小时进入只读诊断（通常从澄清 / 标准档开始），由你们决定

## 你会带走

- 一页对齐结论（先做三件事 + 暂停 / 继续的判断标准）
- 实验 / 数据可信度的共识语言（可以复述给没参会的同事）
- 一页完成证明（便于报销）

## 不包含

不代投、不改生产配置、不替团队写完整年度战略、不承诺销售额。
